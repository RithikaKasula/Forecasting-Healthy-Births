# Forecasting-Healthy-Births
Pregnancy is a period of time that brings a lot of anticipation and hope to the parent's life. Therefore, it becomes essential to create a forecasting system that acts as a guide. This work deals with utilizing SVM variations to forecast healthy births. The "KUfacility_register_data" Kaggle dataset was utilized. The machine learning technique SVM was then used to determine if the fetus was stillborn or an active birth. Using simply SVM, we have gotten 92.7% accuracy, which is not so amazing in the case of obstetric predictions. Therefore, in order to improve accuracy, we employed Nu-SVC, in conjunction with PCA and standard scalar utilizing RandomizedSearchCV. This resulted in an accuracy improvement of 4.8%. In order to improve the accuracy even further, we employed rbf-SVM, demonstrating a nearly 5% increase in accuracy. Further, we employed Nu-SVM in conjunction with the RBF kernel. The result was an accuracy of 97.54%, which is indeed the most acceptable and legitimate outcome.
